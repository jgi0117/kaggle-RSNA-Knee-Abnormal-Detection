# RSNA Knee — 12 Literature-Derived Guidance Files

These 12 Markdown files were prepared from external medical/radiology sources only.

Design principles:
- No rules were derived from the 58 expert-labeled competition reports.
- Recent authoritative or peer-reviewed sources were prioritized.
- ESSR 2024 knee MRI practice recommendations and the ACR 2025 knee MRI practice parameter were used as cross-cutting references where relevant.
- Target-specific recent reviews were added where they provide more detailed diagnostic context.
- The summaries are intended as compact LLM context, not as clinical care instructions or formal competition annotation rules.

Recommended LLM use:
1. Load exactly one target guidance file.
2. Provide the original radiology report.
3. Ask the model to decide whether the report supports the target abnormality according to the supplied medical guidance.
4. Keep the 58 labeled studies only for evaluation/ablation, not for editing these guidance files.
